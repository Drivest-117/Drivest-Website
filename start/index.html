Getting started

Choose learner preparation or instructor

Drivest onboarding reflects whether you are starting learner preparation, actively learning to drive, or running an independent instructor profile.

Pick your stage and language

Future learners and current learners choose their stage, language, and safety preferences before using theory, practice, or navigation features.

Study, practise, or request lessons

Use learning modules, selected-centre practice routes, instructor discovery, and lesson-request flows from the same platform where enabled.

Review progress and next steps

Analytics, readiness signals, booking updates, and confidence history help learners and instructors plan what comes next.

Built for learners and instructors

Drivest helps future learners start earlier, current learners stay clear, and instructors manage enquiries and linked learners where enabled.

For future learners and learners

Start before lessons, then move into local practice and calmer support at the right stage.

  • Start theory, signs, Highway Code, and fines before lessons
  • Choose your stage and preferred language during onboarding
  • Use mastery, quizzes, mock tests, and English Peek
  • Request instructor support where learner-facing marketplace features are enabled
  • Review progress, confidence, and next steps

For instructors

Set up instructor information, availability, and linked learner context without heavy admin.

  • Create a public profile and set availability where listing is enabled
  • Handle lesson requests and booking updates where enabled
  • Link learners and review progress from Instructor Hub where enabled
  • Keep booking updates and learner context in one place
