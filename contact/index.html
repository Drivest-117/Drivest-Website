Coverage methodology

Current route-coverage claims come from the public Drivest route-corpus export used to generate the centre directory and centre pages.

  • Only centres with more than 2 routes are included in the public visibility layer
  • Temporary, backup, broken, and duplicate centre variants are excluded
  • Coverage claims should be refreshed whenever the route corpus changes so search engines and users see the current public layer
