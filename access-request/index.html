What to include

                
Structured learner requests move faster because support can see the route, your driving stage, preferred centre when relevant, and intended start timing in one message.

                
  • Free Learning requests can stay simple if you only need theory-first access
  • Selected-centre plans should include the exact centre or nearby area you want
  • Navigation and bundle requests should include when you want access to start
  • If you are still comparing options, use the message box to explain what you need help deciding

              

              

                
What happens next

                
  • The form prepares an email draft to admin@drivest.uk with the learner-access details already organised
  • If your email app does not open, copy the prepared request and send it manually
  • Support, rollout timing, and learner-access questions are handled through the same inbox
